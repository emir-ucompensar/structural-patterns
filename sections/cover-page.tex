% renderAuthorOrcid - Display an ORCID icon and clicable monospace ID.
%
% The icon comes from the orcidlink package and links to the orcid.org profile.
% The numeric ID is shown in monospace alongside the icon. Both elements sit on
% the same baseline so the visual weight stays balanced.
\newcommand{\renderAuthorOrcid}[1]{%
  \orcidlink{#1}\,{\texttt{\href{https://orcid.org/#1}{#1}}}%
}
