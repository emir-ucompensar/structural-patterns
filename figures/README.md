# Figures

Visual assets used by the paper.

| Directory | Contents |
| --- | --- |
| `images/` | Photographs, screenshots, and raster artwork |
| `diagrams/` | Schemas, flowcharts, and conceptual models |
| `graphs/` | Statistical charts and comparisons |
| `plots/` | Data visualizations generated by research scripts |

Use descriptive kebab-case filenames. Prefer PDF for vector graphics and PNG or
JPEG for raster images; use print-ready resolution when publishing.
